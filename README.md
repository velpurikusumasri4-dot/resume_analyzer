📄 Resume Analyzer — Project Description

Resume Analyzer is an AI-powered web application that analyzes resumes and provides useful insights to help candidates improve their resumes and increase their chances of matching job requirements.

🔹 Key Features
📤 Resume Upload – Users can upload their resume for analysis.
🤖 AI-Based Analysis – Uses AI to analyze resume content.
🧠 Skill Identification – Extracts and identifies important technical and professional skills.
📊 Resume Evaluation – Provides feedback on the quality and relevance of the resume.
🎯 Job Relevance – Helps determine how well a resume matches expected job requirements.
💡 Improvement Suggestions – Gives recommendations to improve resume content.
🌐 Web-Based Interface – Simple interface for interacting with the resume analyzer.
🔧 Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: Python, Flask
AI/API: OpenRouter API
Environment Management: Python-dotenv
API Communication: Flask-CORS
